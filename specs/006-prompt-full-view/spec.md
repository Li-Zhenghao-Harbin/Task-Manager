# 006 Prompt 独立视图、默认展开与复制

> 承接 `specs/005-agent-task-prompts/` 的 prompt 数据与生命周期（本规格不改它们），
> 只调整 prompt 的**呈现位置**、Agent 列表的**默认展开**，并给每条 prompt 加一个**复制**动作。

## 背景

005 把 prompt 面板放在右侧 350px 的详情区里，问题在宽高都不够用：

- prompt 是**要粘贴进别的工具的整段文本**，350px 宽的多行输入框里读不全、改不动；
- 一个任务常常有多条 prompt，右侧一列排下来要不停滚动；
- 右侧面板同时还要承载 Agent 详情，两种内容挤在同一处，语义上是「点了一个任务，结果右侧换成了别的东西」，
  用户容易迷失，只能靠一个「返回」小链接回退。

另外两处体验问题：

- 每个 Agent 的关联任务默认是收起的，进页面只能看到一行行 `应用名-模型名`，
  要判断「这个应用在跑什么」必须逐行点开；
- prompt 抄出去用（贴进终端、贴进别的对话框）目前只能手工选中复制。

## 做什么

### 1. Agent 列表的关联任务区默认展开

- 进入【Agent应用】时，**每个** Agent 行的关联任务区都是展开的，无需点击就能看到它在跑哪些任务。
- 展开/收起改为**显式动作**：点击行首的指示符（`▾` / `▸`）切换这一行。
- 点击行的其它位置只**选中**该 Agent（右侧显示它的详情），**不改变**展开状态。
  （005 里「点行 = 选中 + 切换展开」在默认展开下会变成「第一次点击就把列表收起来」，那是反直觉的。）
- 展开/收起状态只存在于本次运行，不写进存档；重启回到「全部展开」。

### 2. Prompt 管理改为独立视图

- 点击展开区里的任务行 → 打开 **Prompt 管理视图**，它**占据主内容区 + 右侧面板的区域**（横向铺满，左侧导航保留）。
- 视图顶部左侧是【← 返回】按钮，点击回到【Agent应用】列表；返回时各 Agent 的展开/收起状态与进入前一致。
- 视图标题显示任务名与所属 Agent（`应用名-模型名`），右上角是【＋ 添加 Prompt】。
- 打开视图时右侧 Agent 详情面板**不再显示**（整块区域归 Prompt 视图）。
- 视图内提供 005 的全部能力：按序展示、就地编辑、删除、添加、空态文案；改动经防抖落盘。
- 视图内**不显示**保存状态提示（沿用 004 的决定）。

### 3. 每条 prompt 增加【复制】按钮

- 每条 prompt 的卡片右上角除【删除】外增加【复制】；点击把**这条 prompt 的文本**写入系统剪贴板。
- 成功后底部提示「Prompt 已复制」，让用户确认剪贴板已更新。
- 内容为空（只剩空白字符）的 prompt 点击复制时不写剪贴板，提示「这条 Prompt 还是空的，没有可复制的内容」。

### 4. 顺手修掉的丢改动问题（同一流程内的必要修复）

Task 行点击从「切右侧面板」变成「切整个视图」后，切换频率显著变高，005 的缓冲区写法会**静默丢改动**：
编辑中的内容只存在一个全局缓冲区里，缓冲区被换掉（返回、或切到另一个任务）时，防抖还没到点的那一次编辑就没了。

- 未落盘的 prompt 改动改为按 **(Agent, 任务)** 组合入队，与任务/Agent 的 `dirtyTasks` / `dirtyAgents` 同一套节奏。
- 返回列表、切到另一个任务、切到别的导航区，都不会丢改动；重新进入时看到的是权威数据。

## 不做什么

- 不做「一键复制一条任务下的全部 prompt」「复制全部任务」等批量复制。
- 不做 prompt 的粘贴、导入、导出（走整体 `ExportData` / `ImportData`）。
- 不改 prompt 的数据结构、后端接口（`ListAgentPrompts` / `UpdateAgentPrompts`）、生命周期（解除关联保留 / 删任务清除 / 上限与截断）。
- 不改 Agent 应用列表的列结构（应用名 / 关联项目 / 重置时间 / 可用情况），不改任务页、产出页、单位页、日历视图。
- 不做展开状态的持久化，不做「记住上次打开的 prompt」。
- 不做 prompt 的搜索、排序、拖拽、富文本、markdown 预览。

## 验收标准

1. 进入【Agent应用】，所有 Agent 行的关联任务区默认展开；未关联任务的 Agent 展开区仍显示空态文案。
2. 点击行首指示符可收起该行、再点恢复展开，指示符（`▾`/`▸`）与状态一致；点击行的其它位置只选中该 Agent，不改变展开状态。
3. 点击关联任务行后，主内容区与右侧面板区域被 Prompt 管理视图占满，左侧导航仍在，右侧不再出现 Agent 详情面板。
4. 视图顶部有【返回】按钮，点击回到 Agent 列表；返回后各 Agent 的展开/收起状态与进入前一致。
5. Prompt 视图内可添加、编辑、删除 prompt，改动经防抖落盘（行为与 005 一致，空条目不落盘）。
6. 每条 prompt 有【复制】按钮，点击后系统剪贴板内容等于该条 prompt 的文本，并出现成功提示。
7. 空 prompt 点击复制不修改剪贴板，并提示内容为空。
8. 在 Prompt 视图里编辑后立刻点【返回】（防抖未到点）、或立刻切到另一个任务的 prompt，该次编辑**仍然落盘**，不丢失。
9. `gofmt` / `go vet` / `go test ./...` / `vue-tsc` / `wails build` 全部通过，既有 29 项 Go 测试不回归。
