# 007 Agent 面板与 Prompt 卡片布局

## 背景

006 之后，Agent 相关界面有两处空间利用不合意：

1. 右侧 Agent 详情面板里，【关联项目】的可滚区域固定 `max-height:220px`，无论窗口多高都只有这么一小块；
   而面板最后一个元素【删除应用】紧跟其后浮在中间，下方留出一大片空白。用户希望**列表把剩余高度全部吃掉**，
   删除操作**贴到面板最底部**。
2. 【Prompt 管理】视图里每条 prompt 是一个 360px 宽的卡片，靠 `auto-fill` 栅格平铺。卡片一多就变成
   网格状的密集小块，屏幕右侧还有大片没用上的宽度。用户希望**一条 prompt 独占一整行**，
   行内左侧竖排【Prompt N】【复制】【删除】三项，右侧留给文本框。

## 做什么

### A. 右侧 Agent 详情面板

- 【关联项目】列表**撑满面板剩余高度**：面板顶部（标题、应用名/模型名、可用情况、快捷冷却、下次重置时间）
  与底部的【删除应用】保持自身高度不变，中间整块归列表。
- 列表**不再有 220px 上限**，内容超出时在列表内部滚动（整块面板不整体滚动）。
- 【删除应用】固定在面板**最下方**，与上方列表之间用一条分隔线区分。

### B. Prompt 管理视图

- 每条 prompt **独占一行**（宽度铺满 `prompt-board`），取消多列栅格。
- 行内分左右两块：
  - **左列**（固定窄列）自上而下三行：`Prompt N` 文案、【复制】按钮、【删除】按钮；
  - **右侧**：文本框，占据该行其余全部宽度，高度随横向拉伸保持可编辑的舒适高度。
- 【复制】与【删除】在左列内等宽对齐。

## 不做什么

- 不改任何后端逻辑、数据结构与接口签名；`AgentPrompt` 的字段、prompt 的即时保存链路完全沿用 005/006。
- 不改【新增 Agent 应用】弹窗里的【关联项目】选择区（那是另一个 `.agent-projects-editor` 实例，
  按 007 的规则它不受影响，仍保持 `max-height:220px`）。
- 不改 Agent 列表（左栏）与其它视图。
- 不处理仓库目录结构（用户明确跳过）。

## 验收标准

1. 打开某 Agent 详情面板：`agent-project-list` 的高度明显大于 220px，且随窗口高度变化；
   窗口越高列表越高（即 `flex` 生效，不是固定值）。
2. 面板高度不足时，是**列表内部**出现滚动条，面板顶部字段与【删除应用】始终可见。
3. 【删除应用】按钮的底边与面板内容区底部对齐（其下方不再有内容），且位于列表下方。
4. 【新增 Agent 应用】弹窗的关联项目列表高度仍为 `max-height:220px`（未被误改）。
5. Prompt 管理视图：每条 prompt 的卡片宽度 = 容器宽度（一行一条），不存在一行两条的情况。
6. 卡片内布局为横向两栏：`Prompt N`、`复制`、`删除` 三者在左列自上而下排列，
   三者的左边缘对齐，且 `复制`/`删除` 等宽。
7. 文本框位于右栏，其宽度 = 卡片宽度 − 左列宽度 − 间距，且远大于左列宽度。
8. `vue-tsc` 类型检查通过；`wails build` 产出可执行文件；既有 Go 测试无回归。
