# 005 Agent 关联任务的 Prompt 管理规格

> 本规格承接 `specs/003-live-save-and-reset-notify/` 确立的关联模型与
> `specs/004-ui-refinements/` 的即时保存交互，只新增 prompt 这一层数据与对应的展开式界面。

## 背景

002 引入 Agent 应用后，「关联项目」只是一组任务 ID。实际使用中，同一个 Agent 跑不同任务，
需要的是**不同的提示词**：同一个 Codex 应用，跑「ClouESP 8.0」和跑「柒幻 芒种」用的 prompt 完全不同。

现在这些 prompt 只能存在别处，Agent 应用里看不到「这个应用为这个任务准备了什么提示词」。
需要把 prompt 挂在 **(Agent 应用, 任务)** 这个组合上，并在界面上能直接展开进入。

## 做什么

### 1. 数据：prompt 挂在 (Agent 应用, 关联任务) 组合上

- `AgentApp` 新增 `Prompts`：以任务 ID 为键、一个 prompt 列表为值。
- 一条 prompt = **一段纯文本**（无标题、无备注），带一个内部 ID 用于稳定增删。
- prompt 只能挂在该 Agent **已关联的任务**上（`Task.AgentID` 指向该 Agent 且任务类型为 `code`）。
- prompt 的键**不是**独立关系：它依附于关联关系而存在，但**不随关联解除而销毁**（见第 4 条）。

### 2. 界面：Agent 列表可展开为关联任务

- 点击 Agent 列表行 → **同时**选中该 Agent（右侧显示 Agent 详情，行为不变）**并展开**；
  再点一次收起。行首有一个展开指示符（`▸` / `▾`）体现当前状态。
- 展开后，在该行下方按行列出它的全部关联任务（每行一个任务，显示任务名与该任务的 prompt 条数）。
- 点击某个任务行 → 右侧面板切换为**该任务的 Prompt 管理**；任务行高亮表示当前正在查看。
- 展开区在 Agent 收起、被删除、或该任务被解除关联时自动消失。

### 3. 界面：右侧 Prompt 管理面板

- 面板标题区显示当前任务名与所属 Agent（`应用名-模型名`），并提供**返回 Agent 详情**的入口。
- 列表按顺序展示该 (Agent, 任务) 的全部 prompt，每一条：
  - 一个多行文本输入框，就地编辑，**即时保存**（与其它右侧面板一致：防抖，无保存按钮）；
  - 一个删除按钮，点击立即从列表移除并落盘。
- 底部一个「添加 Prompt」按钮：点击后在列表末尾追加一条空 prompt 并聚焦，用户输入后自动落盘。
- 列表为空时展示占位文案。
- 文本为空的 prompt **不落盘**（点了添加但没输入的空条目只存在于界面上，不会污染数据）。

### 4. 生命周期

| 事件 | prompt 的处理 |
| --- | --- |
| 取消任务的关联（从「关联项目」取消勾选 / 任务类型改为非代码） | **保留**，重新关联同一 Agent 后 prompt 仍在 |
| 删除 Agent 应用 | 随之删除（prompt 存在于该 Agent 内） |
| 删除任务 | 清除该任务在所有 Agent 下的 prompt |
| 导入数据 | 按导入内容原样载入 |

## 不做什么

- 不做 prompt 的跨 Agent / 跨任务复用、模板库、收藏。
- 不做版本历史、diff、回滚。
- 不做从任务详情面板进入 prompt 的入口（prompt 的入口只在 Agent 页面）。
- 不做 prompt 的 AI 生成、润色、测试运行。
- 不做 prompt 的导入导出（走整体 `ExportData` / `ImportData` 即可）。
- 不改 003 确立的「`Task.AgentID` 为唯一事实来源」关联模型，prompt 不参与该关联的推导。
- 不改 Agent 应用列表的列结构（应用名 / 关联项目 / 重置时间 / 可用情况）与现有筛选、产出页、日历视图。

## 验收标准

1. `AgentApp` 持久化结构含 `prompts`，键为任务 ID，值为 prompt 列表；旧存档无此字段时按空处理，不报错。
2. Agent 列表行点击后该行展开，下方逐行列出其关联的代码任务；再点一次收起；行首指示符随状态变化。
3. 未关联任何任务的 Agent 展开后显示明确的空态文案，不留空白。
4. 点击展开的任务行后，右侧面板切换为该任务的 Prompt 管理，标题含任务名与 `应用名-模型名`，并有返回 Agent 详情的入口。
5. Prompt 管理面板可添加、编辑、删除 prompt；三个操作都落盘（改动经防抖后到达后端）。
6. 添加后未输入内容的空 prompt 不会出现在持久化数据里。
7. 在 Agent 详情面板取消勾选某任务后：该任务的 prompt **仍存在于数据中**，重新勾选后能在界面上看到。
8. 删除任务后，该任务在所有 Agent 下的 prompt 一并清除（不残留孤儿键）。
9. 删除 Agent 应用后，其它 Agent 的 prompt 不受影响。
10. `UpdateAgentApp` 不能改动 prompt（用旧的 `AgentAppInput` 更新应用名/模型名后，prompt 保持不变）。
11. 后端拒绝给「未关联到该 Agent 的任务」或「非代码任务」写 prompt，并返回明确错误。
12. `gofmt` / `go vet` / `go test ./...` / `vue-tsc` / `wails build` 全部通过。
