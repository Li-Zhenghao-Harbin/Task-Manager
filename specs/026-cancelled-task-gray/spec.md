# 026 — 任务概览列表中「已取消」的任务整行灰显

- 日期：2026-11-06
- 状态：已实现

## 背景

【任务概览】的任务列表里，行样式目前只区分了两态：

- 未完成：白底（`#fff`），标题用正文色
- 已完成：浅绿底（`.task-row.completed{background:#e9f8f0}`），悬停/选中再深一档

「已取消」只在行尾的徽标里体现（`.badge.cancelled` 灰底灰字），行本身与「进行中」长得一模一样。
任务一多，扫列表时看不出哪些已经作废，只能逐行读徽标。

用户要求：**列表中已取消的任务用灰色表示**。

## 做什么

| # | 场景 | 行为 |
| --- | --- | --- |
| 1 | 主任务行（`◆`/`◇`） | 已取消 → 整行浅灰底 `#f2f4f7`，行内文字转 `var(--muted)` |
| 2 | 子任务行（`↳`） | 同上，与主任务行同一套声明 |
| 3 | 上级已删除的孤儿子任务 | 同上 |
| 4 | 悬停 / 选中 | 底色加深到 `#e2e4e7`，仍属于灰阶，不会跳回蓝色高亮 |
| 5 | 行尾徽标 | 灰底再压深一档（`#e3e8ef`），保证在灰行上还能读出轮廓 |
| 6 | 与「上下文任务」叠加 | 两者都是灰，叠加后仍是灰；左侧 3px 竖条保留（那是层级线索，不是状态线索） |
| 7 | 状态筛选 | 【全部任务】/【已取消】两个视图都生效；【进行中】/【已完成】里不会出现灰行 |

## 不做什么

- **不动「已完成」的绿底**。绿色是本项目既有的「完成」语义，这次只补「作废」这一档。
- **不动日历视图**。日历格里的小块已经靠 `.cancelled` 类上色（灰字灰底），用户说的是「列表」。
- **不动 Agent 面板里的任务行**（`.agent-task-row`）。那里没有状态色语义，混进来会破坏 023 定下的对齐。
- **不改数据、不加迁移**，也不改后端任何东西 —— 状态本来就是持久化字段，只是前端没上色。

## 验收标准

1. 列表中存在已取消任务时，该行计算样式 `background-color` 为 `rgb(242, 244, 247)`。
2. 同屏的「进行中」行仍是 `rgb(255, 255, 255)`，「已完成」行仍是 `rgb(233, 248, 240)` —— 三种状态三套底色，两两不等。
3. 已取消行 `.task-name` 的计算色等于 `var(--muted)`（`rgb(113, 128, 154)`），与普通行的正文色（`rgb(23, 35, 59)`）不同。
4. 已取消行的底色是**中性灰**：`max(r,g,b) - min(r,g,b) <= 8`（排除「看起来像灰其实是蓝/绿」）。
5. 点击已取消行后，选中态底色为 `rgb(226, 228, 231)`，仍满足第 4 条的灰阶判据。
6. 子任务行（`.task-row.child`）与孤儿子任务行同样满足第 1–4 条。
7. 徽标 `.badge.cancelled` 的底色 `rgb(227, 232, 239)`，与行底色不同（不会糊成一片）。
8. 对照组（把 `background:#fff;color:inherit` 覆盖回 `.task-row.cancelled`）第 1–4 条必须失败。
9. 019–025 的所有读数不变（滚动归属、卡片贴合、产出摘要裁剪）。

## 影响面

- 前端：`frontend/src/App.vue` —— 三处行模板的 `:class` 各加一个 `cancelled` 键。
- 前端：`frontend/src/App.css` —— 在既有的 `.task-row.completed` 旁边加 `.task-row.cancelled` 三行声明。
- 后端 / 数据：无。
