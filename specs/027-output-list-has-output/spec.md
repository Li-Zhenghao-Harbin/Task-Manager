# 027 — 产出概览的三个列表按「有产出」筛选，不看状态

- 日期：2026-11-12
- 状态：已实现

## 背景

【产出概览】下点【代码】/【文档】/【实施】，右侧列出「对应任务」。这一列现在的筛选条件写死成
「已完成」：

```ts
const outputTasks = computed(() =>
  tasks.value.filter(
    (task) => task.status === 'completed' && (outputFilter.value === 'all' || task.taskType === outputFilter.value),
  ),
)
```

这带来两个方向的偏差，在真实数据（`task-manager-data.json`）里都能看到：

| 方向 | 现象 | 实例 |
| --- | --- | --- |
| 多了 | 已完成但产出全为 0 的任务占着列表 | 【代码】17 条任务里 9 条已完成，其中「ClouESP Docker部署」「方块竞技 重制版」「新阳美发沙龙」产出全 0，却各占一行 |
| 少了 | 有产出但还没完成的任务根本不出现 | 「ClouESP 8.0优化」在填「新增功能 4 / 修改功能 6」，状态进行中，【代码】页看不到它 |

同时菜单上的计数（第 329 行）和顶部的累计卡片（`outputTotals`）**都是按全部任务统计的**，
不看状态。于是【代码】菜单显示 13，列表里只有 9 行、其中 3 行的合计是 0 —— 数字对不上。

用户要求：**只显示有产出的任务（不论是否完成）**。

## 做什么

| # | 场景 | 行为 |
| --- | --- | --- |
| 1 | 【代码】页 | 列出 `taskType === 'code'` 且产出项任一非零的任务，不筛状态 |
| 2 | 【文档】页 | 同上，`taskType === 'document'` |
| 3 | 【实施】页 | 同上，`taskType === 'support'` |
| 4 | 产出全为 0 的任务 | 三个页面里都不出现（含已完成的） |
| 5 | 进行中 / 已取消但有产出 | 出现在列表里，行尾小字照常显示「进行中」/「已取消」 |
| 6 | 列表项与菜单计数的一致性 | 列表里每一行都有非空摘要，合计等于菜单上的数字 |

**「有产出」的判据**：该任务类型对应的产出键（`typeKeys[task.taskType]`）里任一 `!== 0`。

```ts
code     → newFeatures / modifiedFeatures / applications
document → newDocuments / modifiedDocuments / skills
support  → supports
```

判据与 025 的 `taskOutputText()` 完全同一套 —— 列表里不会出现「有这一行，但摘要那栏是空的」。

## 不做什么

- **不算 `result`（结果说明）文本**。「蒙古MDM异常修复」写了结果说明但数字全 0，它属于「做完了事情但没记产出」，
  卡片统计里也不含它。若把文本算作产出，列表与卡片会重新不一致，等于把问题换个方向又犯一次。
- **不改菜单计数和顶部卡片**。它们统计的是「一共产出了多少」，本来就该含进行中的任务，现在只是列表追上了它们。
- **不动【全部产出】页的饼图**。那一页没有「对应任务」列表，只有占比。
- **不改排序**。仍按 `tasks` 数组顺序输出，与改前一致；用户没提排序，混入进行中的任务后顺序仍可预期。
- **不改后端**。产出字段本来就是持久化的，服务端没有任何按状态过滤的逻辑。

## 验收标准

1. 【代码】页列表行数 = 该类型产出项任一非零的任务数（改前为「已完成的」，两者在真实数据下分别是 7 和 9）。
2. 列表中不再出现产出全 0 的已完成任务（「ClouESP Docker部署」「方块竞技 重制版」「新阳美发沙龙」）。
3. 列表中出现了进行中但有产出的任务（「ClouESP 8.0优化」），行尾状态文字为「进行中」。
4. 每个列表项的摘要（`<em>`）都非空 —— 行数与「有非空摘要的行数」相等。
5. 列表项各行摘要的数值合计，等于同一页面菜单项上的计数。
6. 【文档】【实施】两页的列表与改前**逐行一致**（这两类的任务全部「已完成且有产出」，是不变量对照）。
7. 对照组（把 `hasOutput(...)` 换回 `task.status === 'completed'`）第 1、2、3 条必须失败。
8. 019–026 的所有读数不变（滚动归属、卡片贴合、产出摘要裁剪、已取消灰行）。

- 前端样式 / 后端 / 数据：无。
