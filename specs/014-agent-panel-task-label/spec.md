# 014 · Agent 面板「关联项目」改名为「关联任务」

> **已被 015 修订**：本规格里「字段名与类名保持不变」「不改新增 Agent 弹窗的同名标题」两条判断
> 都已在 `specs/015-drop-project-concept/` 推翻——`projectIds` → `taskIds`、
> `.agent-projects-*` → `.agent-tasks-*`、弹窗标题也改成了「关联任务」。
> 本文其余内容（面板标题与行内提示的改法）继续有效。

> 修订 002 引入、007/010 沿用至今的一处界面文案。

## 做什么

1. Agent 右侧详情面板（`.details.agent-details`）里的分区标题由 **【关联项目】改为【关联任务】**。
   该标题位于 `.agent-projects-editor > h3`。
2. 与它指向同一件事的**其它界面文案一并跟随**，避免同一屏出现两个叫法：
   - Agent 列表行展开后、未关联任何代码任务时的提示：
     `未关联任何代码任务，可在右侧「关联项目」中勾选。` → `…可在右侧「关联任务」中勾选。`
3. `outline.md` 里描述界面文案的位置同步改名（字段表、Agent 列表行说明、Prompt 生命周期、
   详情面板布局、数据规则一段）；数据模型相关表述保留「数据字段仍是 `projectIds`」的说明。

## 不做什么

> 以下四条中，前三条**已被 015 推翻**（见文首说明），保留原文以便追溯当时的判断：
> `AgentApp.ProjectIDs` 已改名 `TaskIDs`、三个 CSS 类名已改名、弹窗标题已同步、后端报错文案已改。

- ~~**不改数据模型**：`AgentApp.ProjectIDs` 字段名~~ —— `Task.AgentID` 单一事实来源、
  `syncAgentProjectsLocked()` / `repairAgentLinksLocked()` 的规则确实没动（只是改了名字）。
- ~~**不改 CSS 类名**：`.agent-projects-editor` / `.agent-project-list` / `.agent-project-item` 保持原样~~
  —— 015 改成 `.agent-tasks-editor` / `.agent-task-options` / `.agent-task-option`。
- ~~**不改【新增 Agent 应用】弹窗**里的同名标题~~ —— 015 已同步为「关联任务」。
- ~~**不改后端错误文案**（`app.go` 的 `关联项目必须是代码类型的任务`）~~ —— 015 改为 `只能关联代码类型的任务`。
- 不改布局：面板仍是纵向 flex，关联列表仍吃掉剩余高度、删除应用仍贴底（007）。
- 不改宽度、间距、栅格列数——本轮不新增任何 CSS 规则。

## 验收标准

1. 选中一个 Agent 后，右侧面板的关联区标题文本**恰好**是 `关联任务`。
2. 面板内（整个 `.details.agent-details` 的文本内容）**不再出现** `关联项目` 四个字。
3. 副说明 `仅可选择任务类型为「代码」的任务` 不变；候选项数量与勾选状态不变。
4. 标题单行显示（不换行），左边缘与关联区左边缘对齐。
5. Agent 列表行展开后的提示文案改为 `未关联任何代码任务，可在右侧「关联任务」中勾选。`；
   展开指示符的 `title` 不含 `关联项目`。
6. 布局无回归：关联区仍是删除应用区的前一个兄弟节点，删除应用仍在面板最下方。
7. 改名前后的**文字行宽度一致**（同为 4 个汉字），说明这不是一次会牵动版式的改动。
8. ≤1000px 时详情面板按设计整体隐藏（007 的媒体查询），该行为不变。
