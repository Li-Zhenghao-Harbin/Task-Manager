# 任务管理器功能规格

## 背景

用户需要一个 Windows 本地桌面任务管理器，统一管理主线任务和支线任务。

## 用户故事

1. 作为用户，我可以新建主线任务或关联到主线任务的支线任务。
2. 作为用户，我可以选择任务并查看全部属性。
3. 作为用户，我可以修改任务状态，并补充产出物和总结。
4. 作为用户，我可以按关键字、类型和状态查找任务。

## 验收规则

- 新建任务必须提供任务名、下发人、发布日期、截止日期及任务类型；截止日期不可早于发布日期。
- 支线任务必须指定一个已有的主线任务；主线任务不可指定父任务。
- 新建表单不得显示“产出物”或“总结”；二者仅在任务详情编辑区显示。
- 新建任务状态固定为“进行中”。详情中仅允许变更为“进行中、已完成、已取消”。
- 数据重启后仍可读取；任务列表展示主线到支线的层级关系。

## 非功能要求

- 界面采用现代蓝白配色，初始窗口适配 1280 × 800。
- 所有数据在本机保存，不依赖网络或账户。
- 操作完成后应立即反馈成功或校验错误。
