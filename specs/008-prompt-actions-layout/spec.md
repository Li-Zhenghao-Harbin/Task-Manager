# 008 Prompt 视图细节调整

## 背景

006 把 Prompt 管理做成了独立视图，007 又把每条 prompt 的卡片改成「左列竖排三行 + 右侧文本框」。
用下来有三处不合手：

1. 左上角【← 返回】按钮上的箭头是多余的装饰；
2. 任务名下面单独占一行的 agent 名（`应用名-模型名`）离标题太远，且挤在返回按钮下方；
3. 卡片左列里【复制】和【删除】上下紧挨（间距 8px），误点风险高。

## 做什么

### 1. 返回按钮去掉左箭头

- 左上角按钮文案由 `← 返回` 改为 `返回`，其它行为（点击关闭 Prompt 视图、回到 Agent 应用列表）不变。

### 2. agent 名并入标题行，紧跟在任务名之后

- `应用名-模型名` 从任务名下方独立一行，改为与任务名**同一行**、排在任务名**右侧**；
- 与任务名的间距小于它与返回按钮的间距，视觉上从属于标题；
- 样式仍是原有的灰色小字。

### 3. 【删除】移到卡片底部，远离【复制】

- 卡片内部改为上下两段：上段是「左列（`Prompt N` + 【复制】）+ 撑满的文本框」，
  下段是卡片底部的一条操作区，只放【删除】；
- 【删除】与上方内容用一条分隔线隔开，且与【复制】在视觉上分离（不再上下紧邻）；
- 【删除】的文案、颜色、点击行为（`removePrompt(index)`：立即从列表移除，防抖后整组落盘）不变；
- 【复制】仍留在左列、紧跟 `Prompt N` 下方。

## 不做什么

- 不改后端：prompt 的数据结构、接口、生命周期（005 定的规则）完全不动；
- 不改 Prompt 视图的开关条件、`workspace-full` 横跨两列的布局、视图内部滚动；
- 不改 Agent 详情面板、Agent 列表、新增弹窗的任何布局（007 的成果保持不变）；
- 不改【＋ 添加 Prompt】的位置与行为。

## 验收标准

1. Prompt 视图左上角按钮的文字是 `返回`，不含任何箭头字符；
2. agent 名与任务名在**同一行**（两者垂直中心线大致重合），且 agent 名的左边界在任务名右边界之后；
3. 每条 prompt 卡片：`prompt-card` 的最后一个子元素是含【删除】的操作区；【删除】的上边界在文本框下边界之下；
4. 【复制】仍在左列、位于 `Prompt N` 下方，且与【删除】不在同一行；
5. 点击【删除】后该条 prompt 立即从列表消失（沿用 005/006 的「删除 prompt 不弹确认框」行为），
   并在防抖结束后落盘一次，提交的是剩下的 N-1 条；
6. `go test ./...`、`vue-tsc`、`wails build` 全部通过，无回归。
