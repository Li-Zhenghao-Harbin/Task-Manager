# 010 · Agent 列表信息收敛、字段改名与导航对齐

## 背景

003 给 Agent 列表行加了「关联项目名（顿号连接）」这一列作为辅助信息。实际使用中这列价值不高：
它把行宽吃掉一大块，项目多时还会被 `text-overflow:ellipsis` 截断成半截名字，看不清也点不动；
同样的信息在行展开后的「关联任务」子项和右侧面板的「关联项目」里都能看到，属于重复展示。

另外两处一致性问题：
- 列表行里「重置时间」那一列只显示一个裸日期，没有说明它是什么；右侧面板的字段名是「下次重置时间」，
  但该字段的实际语义是「到点后恢复可用」，叫「重置」不如「可用」直白。
- 左侧菜单的「Agent应用」是 Agent 分组下的子项，被额外缩进了 12px，与「全部任务」「单位管理」等
  同级菜单项的左边缘对不齐，视觉上像是没对齐。

## 做什么

### 1. Agent 列表行：去掉项目名，日期补上前缀

- **删除**行内的「关联项目名」列（即用顿号 `、` 连接所有项目名的那一列），
  以及未关联时显示的占位文案「未关联项目」。项目名在展开的关联任务列表和右侧面板里仍然可见。
- 行内日期列**改为带前缀显示**：`下次可用时间：<日期>`（未设置时沿用 `未设置`）。
  该应用当前可用时仍然显示 `下次可用时间：—`，保持这一列始终有说明文字。
  > **本条已被 011 修订**：应用可用时该格整块不再渲染（列表行与右侧面板规则统一）。
- 行内剩余元素顺序不变：展开指示符 → 应用名-模型名 → 下次可用时间 → 可用情况标签。
- 行的栅格列数随之从 5 列改为 4 列；窄屏（`max-width:1100px`，该断点下日期列本就隐藏）
  从 4 列改为 3 列。

### 2. 右侧 Agent 面板：字段改名 + 与日期框拉开距离

- 字段名「下次重置时间」→「**下次可用时间**」。
- 日期选择框**换到标签下方独立一行**、横向撑满，并与标签文字留出间距——
  当前它作为 `inline-block` 紧贴在标签文字右侧，就是反馈里说的「紧贴着」。
- 该字段仅在应用不可用时出现（`v-if="!selectedAgent.available"`），这个行为不变。
- **附带一致性修改**：「新增 Agent 应用」弹窗里同一个字段也叫「下次重置时间」，一并改名为「下次可用时间」，
  避免同一字段在两处叫法不同。（弹窗那一行是 `setting-row` 的左右布局，输入框位置不动。）

### 3. 左侧菜单：「Agent应用」与同级项左对齐

- 去掉 `.nav-sub` 的额外左缩进，使其文字左边缘与「全部任务」「单位管理」等同级菜单项**完全对齐**。
- 只改缩进，不改字号、颜色、选中态、计数徽标与点击行为。

## 不做什么

- 不改 `AgentApp` / `Task` 的数据结构与后端接口（`resetAt` 字段名不变，仍是 `YYYY-MM-DDTHH:mm` 本地时间）。
- 不改右侧面板「关联项目」列表的高度与滚动行为（沿用 007）。
- 不改 Prompt 视图的任何结构（沿用 009）。
- 不改行的展开/收起逻辑、可用情况标签的文案与配色。
- 不隐藏、不移动左侧菜单的任何一项，只调整「Agent应用」的水平位置。

## 验收标准

1. Agent 列表行内**不含**任何顿号 `、`，也不含「未关联项目」文案；行内 span 数量从 5 个减为 4 个。
2. 日期列的文本以「下次可用时间：」开头；应用不可用时其后是格式化日期。（**由 011 修订**：可用时该格不再渲染，不再有 `—` 分支。）
3. 右侧面板中的字段标签文字为「下次可用时间」，且**不再出现**「下次重置时间」。
4. 该字段的日期框顶边与标签文字底边之间有明确间距（≥ 6px），且日期框宽度撑满面板内容宽度。
5. 左侧「Agent应用」的文字左边缘与「全部任务」「单位管理」的文字左边缘对齐（差值 ≤ 1px）。
6. `gofmt` / `go vet` / `go test ./...` / `vue-tsc` / `wails build` 全部通过，无回归。
