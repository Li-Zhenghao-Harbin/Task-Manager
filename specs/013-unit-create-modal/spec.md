# 013 · 单位管理改用弹窗新增

## 背景

「新建一个实体」这件事，应用里现在有两套做法：

- **全部任务**：页头右上角一个主按钮 `＋ 新建任务`，点击弹出居中表单，字段都在弹窗里；
- **单位管理**：面板内部横排一个输入框加一个 `新增单位` 按钮，就地输入、就地创建。

同一个应用里两种交互并存，用起来是割裂的；而且单位的面板里只有「一行输入框」时，
顶部那一行把列表往下压，视觉上也不像一张干净的列表卡片。

本轮把单位的新建入口对齐到「全部任务」的做法。

## 做什么

1. **删掉面板里的输入行。** `.units-panel` 内的 `.unit-add` 表单（输入框 + `新增单位` 按钮）整块移除，
   面板里不再有任何 `input`。删除后不留空档：`.unit-list` 原先为「表单下方」准备的 `margin-top:18px`
   与 `border-top` 一并去掉，首行直接落在面板的 22px 内边距里。
2. **新建入口移到页头。** 单位管理页的 `<header>` 增加 `div.actions`，里面是主按钮 `＋ 新增单位`
   （`.primary`，与 `＋ 新建任务` 同类名、同位置、同尺寸）。
3. **点它弹窗，弹窗里只有「单位名」。** 复用既有的 `.modal-backdrop / .modal / .modal-title / .form-grid / .actions`
   结构：标题「新增单位」+ 右上 `×`、一个标签为「单位名」的输入框（`required`）、底部 `取消` / `创建单位`。
   弹窗里**不出现任何其它字段**（无 select / textarea / checkbox）。
4. **弹窗宽度收窄到 430**（默认 `.modal` 是 620）——单字段弹窗用不着那么宽。
5. **行为**
   - 提交调 `CreateUnit`，成功后关闭弹窗并刷新列表；失败（后端拒空 / 重名）保持弹窗打开并提示；
   - `取消` 与右上 `×` 都只关闭弹窗，不产生任何调用；
   - 每次打开弹窗，输入框都是空的（草稿被重置）；
   - 输入为空时由 `required` 拦住，不落盘。
6. **空态文案**改为「暂无单位，点击右上角新增。」，与 Agent 面板的「点击右上角新增」措辞统一。

## 不做什么

- 不改后端：`CreateUnit` / `UpdateUnit` / `DeleteUnit` / `SetDefaultUnit` 的签名与校验一律不动。
- 不给单位加字段（仍然只有 `id` + `name`），不改数据文件结构。
- **「修改」不改成弹窗**：它现在走 `prompt()`，本轮只动「新增」入口，不顺手改它。
- 「设为默认」「删除」两个行内按钮保持原样（删除已经走确认弹窗）。
- 不动「全部任务」页的任何部分，包括单位下拉筛选。
- 不新增 CSS 变量或配色，不改主题。

## 验收标准

1. 单位管理面板里 **0 个 `input`、0 个 `form`**，`.unit-add` 与「输入单位名称」placeholder 都不存在。
2. 列表首行顶边距面板顶边 = **22px**（面板内边距），即删掉输入行后没有留下空隙。
3. 单位管理页 `<header>` 里有 `.actions > button.primary`，文案 `＋ 新增单位`；它与「全部任务」的
   `＋ 新建任务`：**class 相同**、到内容区右边缘的距离相同、高度相同、相对 header 顶边的偏移相同。
4. 点击该按钮弹出 `.unit-modal`，标题「新增单位」；弹窗里 `input` 恰好 1 个，
   `select / textarea / input[type=checkbox]` 数量为 0；该输入框的标签文案是「单位名」，并撑满弹窗宽度。
5. 弹窗宽度 ≈ 430px（小于任务弹窗的 620px）。
6. 点【取消】→ 弹窗关闭，`CreateUnit` 调用 0 次。
7. 再次打开弹窗 → 输入框为空；空名提交被 `required` 拦住（`CreateUnit` 仍 0 次），弹窗保持打开。
8. 填入「财务管理部」提交 → `CreateUnit` 恰好 1 次且**入参就是该名字**（没有多余参数），
   弹窗关闭，列表刷新为 3 行且新单位在末尾。
9. 无单位时面板显示「暂无单位，点击右上角新增。」，且页头的主按钮仍在。
10. 「全部任务」页渲染不受影响（工具栏 3 个下拉、`＋ 新建任务` 位置不变）。
11. `gofmt` / `go vet` / `go test ./...` / `vue-tsc` / `wails build` 全部通过。
