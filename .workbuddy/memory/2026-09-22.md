## 006 Prompt 独立视图、默认展开与复制

需求三条：①【Agent应用】界面里的面板默认展开；②prompt 不再放右侧面板，改为一个新界面打开（占主内容+右侧面板区域，带返回按钮）；
③每条 prompt 增加【复制】按钮。

- 产出规格：`specs/006-prompt-full-view/{spec.md, design.md, tasks.md}`，截图 7 张在 `screenshots/`。
- **后端零改动**：006 纯前端（`App.vue` + `App.css`），prompt 的存储/接口/生命周期沿用 005。Go 测试 29 项无回归。

### 实现要点

- **展开状态取反**：`expandedAgentIds` → `collapsedAgentIds`（记「哪些行被收起」，默认空 = 全部展开）。
  新 Agent 天然展开；`deleteAgent` 只需把它从 collapsed 里摘掉。展开/收起**不持久化**。
- **点行 ≠ 切换展开**：拆成 `selectAgent(agent)`（只选中）与 `toggleAgentExpand(agent)`。
  指示符仍是 `<span>`，靠 `@click.stop` 拦掉冒泡（`.agent-row` 是 `<button>`，嵌按钮非法，所以不能把指示符做成 button）。
  这是 006 的必要设计判断：默认展开下若沿用 005 的「点行=选中+切换展开」，用户第一次点行就会把列表收起来。
- **Prompt 独立视图**：`.workspace` 加 `:class="{'workspace-full': promptViewOpen}"` → `grid-column:2 / -1` 横跨两列；
  详情区三个 `aside` **整体包进 `<template v-if="!promptViewOpen">`**（必须整块不渲染，只 `display:none` 会留下栅格项，
  把横跨两列的 workspace 挤到下一行）。打开条件用 computed 复用 `selectedAgentTask`（带关联校验 → 解除关联自动回落）。
- **顺手修掉一个丢改动 bug**：005 是「单个全局 `prompts` 缓冲区 + 单个签名」，换缓冲区是无条件覆盖，
  防抖没到点就返回/切任务会静默丢编辑（签名基线也跟着换，`flushSaves` 判定为不脏，连报错都没有）。
  改成与任务/Agent 同构的队列：`dirtyPrompts: Map<`${agentId}::${taskId}`, {agentId,taskId,list}>` + `loadedPromptKey`。
  - `commitPromptBuffer()` 把缓冲区（过滤空条目后）与**模型里的 `agent.prompts[taskId]`**（服务端权威）比较，不同才入队；
  - `loadPrompts()` 先 commit 旧的再换新的（watch 回调里 `prompts.value` 尚未被覆盖，顺序是关键）；
  - `flushSaves()` 先 commit 当前缓冲区再整队提交，成功后回写模型；
  - **`commitPromptBuffer` 里要补一次 `scheduleSave()`**：输入与「切走」发生在同一次渲染中，
    两个 watcher（`[selectedAgent, selectedAgentTaskId]` 先创建 → 先跑）会让 `queuePrompts` 因 `loadedPromptKey` 已被清空而直接 return，
    没人再调度 flush。漏了这一步，返回后编辑就永远躺在队列里不落盘（正是 07 号截图断言的那个点）。
- **复制**三级降级：`ClipboardSetText`（wails runtime，import 自 `wailsjs/runtime/runtime`）→ `navigator.clipboard.writeText`
  → 临时 `<textarea>` + `execCommand('copy')`。三级都包 try/catch（预览环境没有 `window.runtime` 会直接抛）。
  空内容不写剪贴板，提示「这条 Prompt 还是空的，没有可复制的内容」。
- 样式：删掉 005 右侧面板专用的 `.prompt-list/.prompt-item*/.prompt-editor/.prompt-add/.prompt-footnote` 与 `.link-button`，
  换成 `.workspace-full/.prompt-workspace/.prompt-board/.prompt-grid/.prompt-card*/.prompt-copy/.back-button`。

### 工具坑（新）

- **Bash 里 `(python -m http.server ... &)` 起的服务会随该次工具调用结束一起被杀**（表现为截图全是 `ERR_CONNECTION_REFUSED`，
  且多个视图的 png 字节数完全相同）。预览服务必须用 `run_in_background: true` 常驻，用完 TaskStop。
- 探针的 `text()` 归一化写 `replace(/\s+/g,'')` 会把**词内空格**也删掉（`ClouESP 8.0` → `ClouESP8.0`），
  比对带空格的标题必假失败。用 `replace(/\s+/g,' ').trim()`。
- 行元素（`.agent-row`）的 `textContent` **以指示符 `▾` 开头**，用 `indexOf('名字') === 0` 判「选中哪一行」是错的，
  要改判 `querySelectorAll('.agent-row').indexOf(document.querySelector('.agent-row.selected'))`。
